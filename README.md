# 本手-棋力自現

野狐圍棋棋力追蹤（Elo）。純靜態網站，無需建置。

## 部署到 GitHub Pages
1. 建立新 repo，把本資料夾所有檔案（含 `.nojekyll`）放到 repo 根目錄。
2. Settings → Pages → Source 選 `Deploy from a branch`，分支 `main`、資料夾 `/ (root)`。
3. 約一分鐘後開啟 `https://<帳號>.github.io/<repo>/`。

## 頁面
- `野狐棋力追蹤.html` 首頁
- `取得UID.html` 取得 UID
- `比較.html` 棋手對決

本站非野狐圍棋官方網站，與野狐圍棋無隸屬關係。
